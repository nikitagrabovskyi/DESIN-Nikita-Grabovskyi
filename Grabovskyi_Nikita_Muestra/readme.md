Ejercicio: Ficha web de los carros de combate soviéticos (T-55 → T-80BV)
Enunciado
Vas a crear una página web informativa sobre la evolución de los carros de combate principales soviéticos, desde el T-55 (1958) hasta el T-80BV (1985). Solo se incluyen modelos de la época soviética (hasta 1991).
Objetivos
Repasar la estructura básica de un documento HTML5.
Aplicar CSS externo para dar formato a la página.
Trabajar con VS Code y una estructura de carpetas ordenada.
Estructura de carpetas
```
apellido\_nombre\_muestra/
├── index.html
├── css/
│   └── estilos.css
├── img/
└── README.md
